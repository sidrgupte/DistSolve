# Project 3 — Matrix-Free Parallel Iterative Solvers

Parallel Computing — Stony Brook University

## Overview

C++17/MPI implementation of matrix-free iterative solvers
for the two-dimensional Poisson equation with Dirichlet
boundary conditions.

## Algorithms

- Jacobi
- Red-black Gauss–Seidel
- Conjugate Gradient

## Parallel Computing

- Two-dimensional MPI domain decomposition
- Halo exchange
- Distributed vector operations
- Global reductions
